# 爬升算法方案与选择依据

[简体中文](ascent-options.md) | [English](ascent-options.en.md)

**默认采用不平滑＋10 米峰谷反转阈值。** 在所测的二十次越野跑活动中，该方案整体最接近佳明显示值，同时避免窗口平均进一步削弱短坡。其他平滑窗口保留为显式选项。

## 方案对比

同一批二十次活动使用相同的原始 FIT 坐标与海拔输入，与佳明活动显示的累计爬升、下降比较。平均绝对差异为逐次差值取绝对值后求平均；平台显示值不等于地形真值。

| 方案 | 爬升平均绝对差异（米） | 下降平均绝对差异（米） |
| --- | ---: | ---: |
| 旧版100米窗口 | 110.5 | 111.3 |
| **不平滑＋10米阈值（默认）** | **71.4** | **71.9** |
| 40米平滑＋10米阈值 | 105.9 | 107.0 |
| 20米平滑＋10米阈值 | 88.6 | 89.7 |
| 10米平滑＋10米阈值 | 79.1 | 79.9 |

三条比赛轨迹的累计爬升如下，单位为米；每条轨迹的五种方案使用相同输入，计算距离一致。

| 轨迹 | 旧版100米 | 不平滑＋10米 | 40米＋10米 | 20米＋10米 | 10米＋10米 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 天地留白100K | 5331.6 | 5965.5 | 5521.0 | 5768.6 | 5852.6 |
| 大境门DGW100K | 3635.0 | 3729.0 | 3575.0 | 3651.8 | 3680.8 |
| 大境门MGW50K | 1900.8 | 1960.0 | 1867.8 | 1929.3 | 1949.9 |

比较版本：旧版为 `28270dc`，不平滑为 `461ace7`，40/20/10米方案基于 `dd4b95e`。当前默认已恢复不平滑。个人活动仅公开汇总；MGW50K 原文件未随仓库分发，缺海拔的59点使用统一的距离线性插值副本，涉及约835米和34米两个区间，无法恢复缺失地形细节。

## 天地留白为何差异较大

不平滑与旧版相差约634米，其中 **77.9%集中在CP3→CP6**。未发现可确认删除的孤立大尖峰或CP边界海拔突跳，独立转折点累计也得到5965.47米。

差异主要来自连续起伏跨越10米阈值：例如一段原始下降12.81米，40米平滑后局部幅度约7.73米，便可能不再确认一次下坡转折。这些起伏是否真实，仍需独立高程数据验证。

补充实验中，60米平滑＋10米阈值得到5290.0米，100米平滑＋10米阈值得到4895.4米；仅每5米重新取点、不做平均平滑，得到5935.7米。接近高驰约5300米不能单独证明方案更准确，也不据此删点或调参。

## 如何选择

默认无需额外配置，等价于：

```json
{
  "ascent_method": "hysteresis",
  "ascent_smoothing_m": 0,
  "ascent_threshold_m": 10
}
```

- **不平滑＋10米阈值**：保留清理后原始海拔的峰谷；超过阈值的噪声仍可能计入爬升。
- **显式平滑**：将 `ascent_smoothing_m` 设为10、20、40等正数；窗口平均可能削弱真实短坡。窗口为完整宽度，如40米表示前后各20米。
- **窗口法**：选择 `ascent_method: "window"` 和 `ascent_smoothing_m: 100`，不使用反转阈值；当前实现包含边界修复，不保证复现表中旧版数值。

10米阈值针对累计反向变化，不是相邻点高差。显示曲线独立使用5米采样、20米平滑；默认保留重复点处理和孤立尖峰修正。详细规则见[模型](model.md#累计爬升与下降)，参数见[配置](configuration.md#旧窗口口径与显式过滤)。
